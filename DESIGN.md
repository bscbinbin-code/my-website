# BIN Photography Portfolio Design References

This file is the design reference entry point for this project.

Use the full `design-md-library/design-md/` collection as the project design inspiration library. Do not treat one DESIGN.md as the only source. For page layout, motion, typography, gallery behavior, buttons, navigation, captions, color, and photographic storytelling, choose references from the full library and adapt them into a BIN-branded photography portfolio.

## How To Use

- Serve the current project first: black, premium, photographic, BIN-branded, and Kookie-inspired.
- Do not copy any single brand wholesale. Extract useful design language and merge it into a distinct BIN visual system.
- Before changing a specific page or section, read 3 to 8 relevant files from `design-md-library/design-md/*/DESIGN.md`.
- For broad visual upgrades, compare across the full collection and summarize shared patterns before implementing.
- `design-md-library/design-md/runwayml/DESIGN.md` remains one of the strongest references for cinematic, full-bleed, image-led design, but it is not the only reference.

## Current Project Direction

- Intro: black screen, small premium white `BIN`, hollow or masked reveal, then forward exit.
- Hero: full-screen photography with oversized split `B`, `I`, `N`.
- Location: subway/city text-scroll atmosphere.
- Work/gallery: dark grayscale mood, motion blur, HUD/REC details, soft blurred `MY WORK`, floating photo cards, red scroll glow.
- Overall: cinematic, premium, photographic, restrained, tactile, not generic SaaS.

## Practical Selection Guide

- Photography, cinema, full-bleed visuals: `runwayml`, `nike`, `playstation`, `theverge`, `wired`
- Premium black brand energy: `bugatti`, `ferrari`, `lamborghini`, `bmw-m`, `tesla`
- Minimal black-white precision: `apple`, `vercel`, `linear.app`, `stripe`, `notion`
- Tech, HUD, tool-like details: `cursor`, `raycast`, `warp`, `opencode.ai`, `voltagent`
- Editorial and magazine structure: `theverge`, `wired`, `airbnb`, `pinterest`
- Modern web motion and product craft: `framer`, `webflow`, `figma`, `lovable`

## Rule

All future visual work should treat this library as an active reference asset. When design judgment is needed, read the relevant DESIGN.md files first, then implement in a way that fits the existing codebase and the BIN photography direction.
